GOT QUESTIONS?

FREQUENTLY ASKED QUESTIONS

What is Cubiq Launcher?

Cubiq Launcher is an Android launcher engineered to run authentic Minecraft Java Edition on mobile devices with high-performance graphics wrappers (Krypton and Kopper Zink) and custom virtual controls.

Where can I download Cubiq Launcher?

Use the Download button on this page. All buttons link directly to the latest stable APK release from the official GitHub repository.

Does Cubiq Launcher include Minecraft?

Cubiq Launcher is a separate launcher project. Minecraft Java Edition is a product of Mojang Studios. To play online multiplayer, an official Minecraft account is required.

Which Android devices are supported?

Cubiq is optimized for Android 8.0 and above with 64-bit ARM processors (ARM64-v8a). Devices with Vulkan 1.2+ support can also utilize the Kopper Zink backend.

Can I install Fabric mods and shaders?

Yes! Cubiq features built-in mod loader setups for Fabric and Forge. You can easily install optimization mods such as Sodium, Lithium, and Iris shaders.
